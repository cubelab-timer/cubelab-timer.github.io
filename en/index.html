Storage status

Your records are saved only in this browser. Clearing browsing data, private/incognito mode, or another browser or device will not show them, so export a backup now and then.

Move your records from csTimer (3 steps)

  1. Open csTimer and press its export button
    Phone: the 2nd icon from the left in the bottom bar (it has no label and looks like)
    Computer: the “EXPORT” button on the left side
    Open csTimer
  2. In the dialog, press “Export to file”
    A file named like “cstimer_date.txt” is saved. On iPhone it goes to Downloads in the Files app; on Android, to the Download folder.
  3. Press the button below and choose that file
    On a computer you can also drag the file onto this box. Open csTimer and this timer on the same device.

① Export a backup

The CubeLab backup (JSON) is the important one: it holds everything (events, sessions, scrambles and battle results) and restores it all later.

Files cannot be saved from this view, so copy everything below, paste it into a text editor and save it.

② Import a file

Choose a CubeLab backup (.json) or a file exported from csTimer (.txt / .json). Your current records stay, and the file's records are added. Importing the same file twice never creates duplicates.

How to…

After moving from csTimer
  1. Each csTimer session becomes a session of the same event here. Pick it in the session menu at the top right of the Timer tab to see stats from all your past solves.
  2. Events are detected from your csTimer settings. Unknown ones are added as a new event named “csTimer …”.
  3. If you keep practicing in csTimer, just export and import again: only the new solves are added.
Move records from here to csTimer
  1. Under “① Export a backup”, press “Export for csTimer”.
  2. Export and keep your csTimer data first. Importing into csTimer replaces the data currently in csTimer.
  3. In csTimer, press “EXPORT” → “Import from file” and choose the file.
Move to another phone or computer
  1. On your current device, press “Export backup (JSON)” and save the file.
  2. Send the file to the new device (email, AirDrop, Google Drive, iCloud, a chat app…).
  3. Open this timer on the new device and choose the file under “② Import a file”.
Move to a new URL
  1. Records are saved separately for each URL. A timer at a new URL does not show the old URL's records automatically.
  2. In the timer at the old URL, press “Export backup (JSON)”.
  3. In the timer at the new URL, choose the file under “② Import a file” to bring everything over.
If records went missing
  1. First, check that you are using your usual browser and the same URL (private mode and in-app browsers count as different).
  2. If “Automatic backup” on this tab shows a date, press “Restore from automatic backup” to add back the previous day's records.
  3. If you exported a backup file, restore it with “② Import a file”.

App updates are built never to erase records, but data deleted by the browser itself cannot be prevented. Keep important records in a file too.
